# Navicat 功能说明

### 一、表（Table）

真正存数据的地方。数据按行、列存放，像 Excel，所有增删改查最终操作的都是表。

示例：

students 表：

| id | name | age | gender | score |
| ---- | ---- | ---- | ---- | ---- |
| 1 | 张三 | 18 | 男 | 85.5 |
| 2 | 李四 | 19 | 女 | 92.0 |

### 二、视图（View）

虚拟表，本质是一条存起来的 SELECT 语句，用起来像表，但不存真实数据。

示例：

```sql
CREATE VIEW male_students AS
SELECT name, score FROM students WHERE gender = '男';
```

以后直接：

```sql
SELECT * FROM male_students;
```

好处：简化复杂查询、隐藏敏感字段、不用每次重写长 SQL。

注意：视图不存数据，改原表数据，视图结果也跟着变。

### 三、函数（Function）

可重复使用的 SQL 代码块，封装好逻辑，像函数一样调用，返回一个结果。

示例：

```sql
CREATE FUNCTION get_avg_score()
RETURNS DECIMAL(5,2)
BEGIN
    DECLARE avg_score DECIMAL(5,2);
    SELECT AVG(score) INTO avg_score FROM students;
    RETURN avg_score;
END;
```

以后调用：

```sql
SELECT get_avg_score();
```

用途：把常用计算逻辑封装起来，多处复用，不用重复写。

新手阶段可以先不管函数，等 SQL 熟练了再学。

### 四、查询（Query）

你在“新建查询”里写的 SQL，保存后会出现在这里，相当于一个 .sql 文件。

写了一条复杂 SQL，想留着以后用，点“保存”，起个名字，它就出现在“查询”分类下，下次双击就能打开，不用重写。

注意：查询里存的只是 SQL 文本，不是数据，也不是表。

### 五、一句话对比

- 表：真正存数据的地方，存数据，必须学。
- 视图：存起来的 SELECT，虚拟表，不存数据，稍后学。
- 函数：可复用的 SQL 代码块，不存数据，以后学。
- 查询：你保存的 SQL 文本，不存数据，会用就行。
