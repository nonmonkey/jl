# MySQL 初始自带的数据库

安装完 MySQL 后，连接里会自动出现几个库。它们分两类：

- 系统库：MySQL 自己用的，不能删
- 示例库：官方给你练手的，可以删但建议留着

---

## 一、系统库（4 个，不能删）

| 数据库 | 作用 | 能删吗 |
|--------|------|--------|
| information_schema | 存元数据：有哪些库、哪些表、字段类型等 | 不能删 |
| mysql | 存 MySQL 自己的配置：用户、权限、密码 | 不能删 |
| performance_schema | 存性能监控数据，用于调优 | 不能删 |
| sys | 把 performance_schema 数据整理成好读的视图 | 不能删 |

### 1. information_schema

数据库的"说明书"。

- 记录：有哪些数据库、每张表有哪些字段、字段什么类型
- 你写 SHOW DATABASES、DESC students，底层查的就是它
- 只读，不能改

### 2. mysql

MySQL 的"户口本"。

- 存用户账号、密码、权限
- 比如 root 用户的密码就存在这里
- 你 CREATE USER、GRANT 改的就是它
- 别手动改里面的表，容易把 MySQL 搞坏

### 3. performance_schema

MySQL 的"体检报告"。

- 记录服务器运行时的性能数据：SQL 执行耗时、锁等待、连接数等
- 用于性能分析和调优
- 平时不用管

### 4. sys

performance_schema 的"翻译版"。

- 把 performance_schema 里难读的数据，整理成人类友好的视图
- 比如查"哪些 SQL 最慢"
- 平时不用管

---

## 二、示例库（2 个，可删但建议留着）

| 数据库 | 内容 | 用途 |
|--------|------|------|
| sakila | 虚构的 DVD 租赁店数据 | 练复杂查询、多表 JOIN |
| world | 全球国家/城市/语言数据 | 练基础查询、统计 |

### 1. sakila

模拟一个 DVD 租赁店，包含：

- actor：演员
- film：电影
- customer：顾客
- rental：租赁记录
- payment：付款记录
- store：门店
- inventory：库存

表之间有关联，非常适合练 JOIN。

### 2. world

全球地理数据，只有 3 张表：

- country：国家（代码、名称、大洲、面积、人口）
- city：城市（名称、所属国家、人口）
- countrylanguage：各国语言

表少、字段简单，适合新手练基础查询。

---

## 三、你要动哪些？

| 库 | 你要动吗 |
|----|----------|
| information_schema | 别动 |
| mysql | 别动 |
| performance_schema | 别动 |
| sys | 别动 |
| sakila | 可以拿来练手 |
| world | 可以拿来练手 |
| 你自己建的库（如 learn_sql） | 主要动这个 |

> 原则：四个系统库一律不碰；示例库可以拿来练；自己建的库是主战场。
