# 模块 1 —— 建库建表 + 数据类型

## 一、概念

| 概念 | 通俗理解 | 例子 |
|------|----------|------|
| 数据库（Database） | 一个"仓库"，里面放很多表 | `school` 学校库 |
| 表（Table） | 像 Excel 的一张表，有行有列 | `students` 学生表 |
| 字段（Column） | 表的一列，描述一个属性 | "姓名""年龄" |
| 记录（Row） | 表的一行，一条完整数据 | 张三，18，男 |

> 关系：库 → 表 → 行（记录）/ 列（字段）

---

## 二、建库（CREATE DATABASE）

```sql
-- 创建数据库
CREATE DATABASE school;

-- 库不存在才创建，已存在就跳过（不报错）
CREATE DATABASE IF NOT EXISTS duhe_test;

-- 常用：创建时直接指定字符集（推荐）
CREATE DATABASE school
  DEFAULT CHARACTER SET utf8mb4
  DEFAULT COLLATE utf8mb4_unicode_ci;
```

> 💡 实际开发中基本都写成 `CREATE DATABASE IF NOT EXISTS xxx;`，脚本重复执行也不会报错。

其他常用操作：

```sql
SHOW DATABASES;                        -- 查看所有库

USE school;                            -- 切换到 school 库，之后的语句都在这个库下执行

SELECT DATABASE();                     -- 查看当前正在用哪个库

DROP DATABASE IF EXISTS school;        -- 删库（危险！库里的表全没了）
```

> ⚠️ 建库时记得指定 `utf8mb4`，否则中文和 emoji 可能出问题（详见 `../navicat/字符集.README.md`）。

## 三、建表（CREATE TABLE）

### 基本语法

```sql
USE school;

-- 表不存在才创建（实际开发基本都这样写）
CREATE TABLE IF NOT EXISTS students (
    id      INT          PRIMARY KEY AUTO_INCREMENT,  -- 学号
    name    VARCHAR(50)  NOT NULL,                    -- 姓名
    age     INT,                                      -- 年龄
    gender  CHAR(2),                                  -- 性别
    score   DECIMAL(5,2),                             -- 成绩
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP     -- 创建时间
);
```

### 逐行读法

建表就像"给每一列定规矩"：

```
字段名   数据类型   约束（可选）
name     VARCHAR(50)  NOT NULL     ← 姓名列，最长 50 字符，不允许为空
```

### 其他常用操作

**① 查看 / 删表 / 清空**

```sql
SHOW TABLES;                            -- 查看当前库有哪些表

DESC students;                          -- 查看表结构（也可以写 DESCRIBE）

DROP TABLE IF EXISTS students;          -- 删表（危险！表和数据全没了）

TRUNCATE TABLE students;                -- 清空表数据，保留表结构
```

**② ALTER —— 加列（ADD）**

```sql
ALTER TABLE students ADD email VARCHAR(100);             -- 加一列，放在最后面（默认）

ALTER TABLE students ADD email VARCHAR(100) FIRST;       -- 加一列，放在最前面

ALTER TABLE students ADD email VARCHAR(100) AFTER name;  -- 加一列，放在 name 后面

ALTER TABLE students ADD status VARCHAR(10) DEFAULT '正常' AFTER name;  -- 加一列，带默认值
```

**③ ALTER —— 改列（MODIFY，列名不变）**

```sql
ALTER TABLE students MODIFY age BIGINT;                  -- 改已有列的类型（数据不变）

ALTER TABLE students MODIFY name VARCHAR(100) NOT NULL;  -- 把 name 改为必填

ALTER TABLE students MODIFY name VARCHAR(100) NULL;      -- 把 name 改回选填（允许为空）

ALTER TABLE students MODIFY remark VARCHAR(50) DEFAULT '无';  -- 改默认值
```

> ⚠️ 改成必填（NOT NULL）前，如果列里已有 NULL 值，语句会失败，要先填掉：

```sql
UPDATE students SET name = '未知' WHERE name IS NULL;  -- 先填掉 NULL
ALTER TABLE students MODIFY name VARCHAR(50) NOT NULL; -- 再改必填
```

**④ ALTER —— 改列名（CHANGE）**

```sql
ALTER TABLE students CHANGE hight height DECIMAL(5,2);   -- 改列名（顺便也能改类型）
```

**⑤ ALTER —— 删列（DROP COLUMN）**

```sql
ALTER TABLE students DROP COLUMN email;                  -- 删一列
```

### ALTER 改结构速查

都是改**表结构**（不是改数据）：

| 关键字 | 干什么 |
|--------|--------|
| `ADD` | 加一列 |
| `MODIFY` | 改已有列的类型 / 约束，列名不变 |
| `CHANGE` | 类似 MODIFY，但还能顺便改列名 |
| `DROP COLUMN` | 删一列 |

> ⚠️ `MODIFY` / `CHANGE` 是把列的定义**整个重写**，原来有的约束（如 NOT NULL、DEFAULT）如果新定义里没写，就会被丢掉。

## 四、数据类型

### 常用类型速查表

**数字类型**

| 类型 | 大小 | 范围 | 什么时候用 |
|------|------|------|------------|
| TINYINT | 1 字节 | -128 ~ 127 | 年龄、状态标志（0/1） |
| INT | 4 字节 | 约 ±21 亿 | 最常用的整数 |
| BIGINT | 8 字节 | 超大整数 | 订单量、文件 ID 等超大的数 |
| DECIMAL(M,D) | 可变 | 精确小数 | **金额、成绩，必须用这个** |
| FLOAT / DOUBLE | 4 / 8 字节 | 近似小数 | 科学计算，别用来存钱 |

**字符串类型**

| 类型 | 特点 | 什么时候用 |
|------|------|------------|
| CHAR(n) | 定长，不足补空格 | 固定长度，如性别、手机号 |
| VARCHAR(n) | 变长，n 是上限（最大 65535） | 最常用的字符串 |
| TEXT | 大文本，最大约 64KB | 文章内容等长文本 |

**日期时间类型**

| 类型 | 格式 | 什么时候用 |
|------|------|------------|
| DATE | 2026-10-08 | 只存日期，如生日 |
| TIME | 12:30:00 | 只存时间 |
| DATETIME | 2026-10-08 12:30:00 | 日期 + 时间，最常用 |
| TIMESTAMP | 同 DATETIME | 自动记录创建/修改时间 |

### 两个常见坑

**1. 为什么金额不能用 FLOAT？**

```
0.1 + 0.2 = 0.30000000000000004   ← 二进制存不全，会出错
```

所以：涉及钱的一律用 `DECIMAL(M,D)`，M 是总位数，D 是小数位数。
例如 `DECIMAL(10,2)` = 最多 10 位数字，其中 2 位小数（最大 99999999.99）。

**2. CHAR 和 VARCHAR 怎么选？**

- 长度固定（性别、手机号）→ `CHAR`
- 长度不定（姓名、地址）→ `VARCHAR`

## 五、常见约束（Constraint）

| 约束 | 作用 | 例子 |
|------|------|------|
| PRIMARY KEY | 主键，唯一标识一行，不能重复、不能为空 | 学号、身份证号 |
| NOT NULL | 不允许为空 | 姓名必填 |
| UNIQUE | 不能重复（允许多个 NULL，因为 NULL 不算相等） | 邮箱、手机号 |
| DEFAULT | 不填时给默认值 | 状态默认 0 |
| AUTO_INCREMENT | 自动递增，常和主键一起用 | id 自动 1、2、3… |

> 主键是重中之重：以后"多张表关联"全靠它。

## 六、小练习

```sql
-- 1. 建一个班级库
CREATE DATABASE IF NOT EXISTS classroom
  DEFAULT CHARACTER SET utf8mb4
  DEFAULT COLLATE utf8mb4_unicode_ci;

USE classroom;

-- 2. 建一张课程表
CREATE TABLE IF NOT EXISTS courses (
    id        INT          PRIMARY KEY AUTO_INCREMENT,
    title     VARCHAR(100) NOT NULL,
    teacher   VARCHAR(50),
    credits   DECIMAL(3,1),
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 3. 验证
SHOW TABLES;
DESC courses;
```

## 七、本节总结

- 库装表，表装行和列，一行就是一条记录
- 建库建表都是 `CREATE ...`，删都是 `DROP ...`，删之前三思
- 实际开发基本都写 `IF NOT EXISTS`（建）/ `IF EXISTS`（删），脚本可重复执行
- 数字：整数用 `INT`，钱用 `DECIMAL`，别用 `FLOAT`
- 字符串：短而固定用 `CHAR`，其他用 `VARCHAR`
- 主键 + 自增，是每张表的基本功
