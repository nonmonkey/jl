## 一、什么是子查询？

**子查询 = 一条 SQL 里嵌套另一条 SQL。**

- 里面的叫**子查询**
- 外面的叫**主查询**
- 子查询的结果，给主查询用

---

## 二、子查询的三种常见位置

### 1. WHERE 里用子查询

场景：查分数高于平均分的学生。

```sql
SELECT name, score
FROM students
WHERE score > (SELECT AVG(score) FROM students);
```

执行逻辑：

1. 先跑子查询 `SELECT AVG(score) FROM students` → 得到平均分
2. 再跑主查询，用这个平均分做条件

### 2. FROM 里用子查询（派生表）

```sql
SELECT class_id, AVG(score) AS 平均分
FROM (
    SELECT class_id, score FROM students2 WHERE score > 60
) AS t
GROUP BY class_id;
```

子查询的结果当成一张**临时表**，必须起别名（这里叫 `t`）。

### 3. SELECT 里用子查询（标量子查询）

```sql
SELECT
    name,
    score,
    (SELECT AVG(score) FROM students) AS 全班平均分
FROM students;
```

每行都会带上"全班平均分"这一列。

---

## 三、子查询返回不同类型

| 子查询返回 | 用在哪 | 例子 |
|------------|--------|------|
| 单个值 | `=` `>` `<` `>=` `<=` | `WHERE score > (SELECT AVG(score) ...)` |
| 一列多行 | `IN` | `WHERE id IN (SELECT class_id ...)` |
| 多列多行 | `FROM` 派生表 | `FROM (SELECT ...) AS t` |

### 例子：IN + 子查询

```sql
-- 查所有在一班的学生
SELECT name
FROM students2
WHERE class_id IN (
    SELECT id FROM classes WHERE class_name = '一班'
);
```

---

## 四、EXISTS —— 存在性判断

场景：查有学生的班级。

```sql
SELECT class_name
FROM classes c
WHERE EXISTS (
    SELECT 1 FROM students2 s WHERE s.class_id = c.id
);
```

- `EXISTS` 只判断子查询**有没有结果**，不关心具体内容
- 有 → 返回 true，保留该行
- 没有 → 返回 false，过滤掉

**NOT EXISTS**：反过来，查**没有**学生的班级。

```sql
SELECT class_name
FROM classes c
WHERE NOT EXISTS (
    SELECT 1 FROM students2 s WHERE s.class_id = c.id
);
```

> 💡 `EXISTS` 里的 `SELECT 1` 只是占位，写 `SELECT *` 或 `SELECT class_id` 效果一样，写 1 最省。

---

## 五、子查询 vs JOIN

很多场景两者都能做，区别：

| | 子查询 | JOIN |
|---|---|---|
| 可读性 | 逻辑清晰，分层 | 表多时字段多 |
| 性能 | 有时较慢 | 通常更快 |
| 适用 | 简单条件、存在判断 | 需要多表字段 |

一般建议：

- 能用 JOIN 就用 JOIN（性能更好）
- 逻辑复杂、需要分层理解时用子查询

## 六、综合实战（把前 5 个模块串起来）

场景：学生 + 班级，已有表：`classes`、`students2`。

### 实战 1：查每个学生的姓名、分数、班级名

```sql
SELECT s.name, s.score, c.class_name
FROM students2 s
JOIN classes c ON s.class_id = c.id;
```

### 实战 2：查每个班级的人数、平均分、最高分

```sql
SELECT
    c.class_name,
    COUNT(*) AS 人数,
    AVG(s.score) AS 平均分,
    MAX(s.score) AS 最高分
FROM students2 s
JOIN classes c ON s.class_id = c.id
GROUP BY c.class_name;
```

### 实战 3：查平均分高于 85 的班级

```sql
SELECT
    c.class_name,
    AVG(s.score) AS 平均分
FROM students2 s
JOIN classes c ON s.class_id = c.id
GROUP BY c.class_name
HAVING AVG(s.score) > 85;
```

### 实战 4：查分数高于全班平均分的学生

```sql
SELECT name, score
FROM students2
WHERE score > (SELECT AVG(score) FROM students2);
```

### 实战 5：查没有学生的班级

```sql
SELECT class_name
FROM classes c
WHERE NOT EXISTS (
    SELECT 1 FROM students2 s WHERE s.class_id = c.id
);
```

### 实战 6：查每个班级分数最高的学生

```sql
SELECT s.name, s.score, c.class_name
FROM students2 s
JOIN classes c ON s.class_id = c.id
WHERE s.score = (
    SELECT MAX(score) FROM students2
    WHERE class_id = s.class_id
);
```

> ⚠️ 这是**相关子查询**：子查询用到了外层的 `s.class_id`，**每行都会重新跑一次**。逻辑强，但比实战 4 那种"只跑一次"的子查询慢。

## 七、SQL 执行顺序总复习

```
FROM → JOIN → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT
```

记住这个，写复杂 SQL 就不会乱。

---

## 八、常见错误

| 错误 | 原因 |
|------|------|
| 子查询返回多行，却用 `=` | 应该用 `IN` 或 `ANY` |
| `FROM (SELECT ...)` 报错 | MySQL 要求派生表**必须有别名**，如 `AS t` |
| 相关子查询没结果 | 内外层字段要对应，`WHERE class_id = s.class_id` 别写错 |
| 子查询性能差 | 能用 JOIN 就换 JOIN |

## 九、练习任务

1. 查分数高于平均分的学生
2. 查所有在一班的学生（用子查询）
3. 查有学生的班级（`EXISTS`）
4. 查没有学生的班级（`NOT EXISTS`）
5. 查每个班级的人数、平均分
6. 查平均分最高的班级
7. 查每个班级分数最高的学生

参考：

```sql
-- 1.
SELECT name, score FROM students2
WHERE score > (SELECT AVG(score) FROM students2);

-- 2.
SELECT name FROM students2
WHERE class_id IN (SELECT id FROM classes WHERE class_name = '一班');

-- 3.
SELECT class_name FROM classes c
WHERE EXISTS (SELECT 1 FROM students2 s WHERE s.class_id = c.id);

-- 4.
SELECT class_name FROM classes c
WHERE NOT EXISTS (SELECT 1 FROM students2 s WHERE s.class_id = c.id);

-- 5.
SELECT c.class_name, COUNT(*) AS 人数, AVG(s.score) AS 平均分
FROM students2 s
JOIN classes c ON s.class_id = c.id
GROUP BY c.class_name;

-- 6.（先分组算平均分，再取最大的）
SELECT c.class_name, AVG(s.score) AS 平均分
FROM students2 s
JOIN classes c ON s.class_id = c.id
GROUP BY c.class_name
ORDER BY 平均分 DESC
LIMIT 1;

-- 7.（相关子查询）
SELECT s.name, s.score, c.class_name
FROM students2 s
JOIN classes c ON s.class_id = c.id
WHERE s.score = (
    SELECT MAX(score) FROM students2
    WHERE class_id = s.class_id
);
```

## 十、本节总结

- 子查询：SQL 里套 SQL，可放在 `WHERE` / `FROM` / `SELECT`
- `IN`：子查询返回**一列多行**时用
- `EXISTS` / `NOT EXISTS`：判断"有没有"
- 相关子查询：子查询引用了外层字段，每行重跑一次，强但慢
- 综合实战：`JOIN + GROUP BY + HAVING + 子查询`，就是真实开发里最常写的
- 执行顺序：`FROM → JOIN → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT`
