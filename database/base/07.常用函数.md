# 模块 7 —— SQL 常用函数

> 按 4 类讲：字符串、数字、日期、条件。每类都配例子。
> 前置：前面所有模块，函数在 SELECT / WHERE / ORDER BY 里都能用。

---

## 一、字符串函数

| 函数 | 作用 | 例子 | 结果 |
|------|------|------|------|
| `CONCAT` | 拼接 | `CONCAT('a','b')` | `ab` |
| `CONCAT_WS` | 带分隔符拼接 | `CONCAT_WS('-','a','b')` | `a-b` |
| `SUBSTRING` | 截取（别名 `SUBSTR`） | `SUBSTRING('hello',1,3)` | `hel` |
| `REPLACE` | 替换 | `REPLACE('abc','b','x')` | `axc` |
| `TRIM` | 去首尾空格 | `TRIM(' a ')` | `a` |
| `UPPER` | 转大写 | `UPPER('abc')` | `ABC` |
| `LOWER` | 转小写 | `LOWER('ABC')` | `abc` |
| `LENGTH` | **字节**长度 | `LENGTH('中')` | `3` |
| `CHAR_LENGTH` | **字符**长度 | `CHAR_LENGTH('中')` | `1` |
| `LEFT` | 左边 n 个 | `LEFT('hello',2)` | `he` |
| `RIGHT` | 右边 n 个 | `RIGHT('hello',2)` | `lo` |

### 例子

```sql
-- 拼接姓名和分数
SELECT CONCAT(name, '：', score, '分') AS 信息 FROM students;

-- 姓名转大写
SELECT UPPER(name) FROM students;

-- 截取姓名前 1 个字
SELECT SUBSTRING(name, 1, 1) FROM students;

-- 替换
SELECT REPLACE(name, '张', '李') FROM students;
```

> ⚠️ `LENGTH` 按**字节**算，`CHAR_LENGTH` 按**字符**算。utf8mb4 下一个汉字占 3 字节，所以 `LENGTH('中')` = 3、`CHAR_LENGTH('中')` = 1。

> 💡 `SUBSTR` 是 `SUBSTRING` 的别名，完全等价，从 **1** 开始数（不是 0）。

## 二、数字函数

| 函数 | 作用 | 例子 | 结果 |
|------|------|------|------|
| `ROUND` | 四舍五入 | `ROUND(3.567, 1)` | `3.6` |
| `CEIL` | 向上取整 | `CEIL(3.1)` | `4` |
| `FLOOR` | 向下取整 | `FLOOR(3.9)` | `3` |
| `ABS` | 绝对值 | `ABS(-5)` | `5` |
| `MOD` | 取余 | `MOD(10, 3)` | `1` |
| `POW` | 幂 | `POW(2, 3)` | `8` |
| `SQRT` | 平方根 | `SQRT(16)` | `4` |

### 例子

```sql
-- 分数四舍五入到整数
SELECT name, ROUND(score) FROM students;

-- 分数取整
SELECT name, FLOOR(score) FROM students;
```

## 三、日期函数

| 函数 | 作用 | 例子 |
|------|------|------|
| `NOW()` | 当前日期+时间 | `2024-01-01 12:00:00` |
| `CURDATE()` | 当前日期 | `2024-01-01` |
| `CURTIME()` | 当前时间 | `12:00:00` |
| `DATE_FORMAT` | 格式化日期 | `DATE_FORMAT(NOW(),'%Y-%m-%d')` |
| `DATEDIFF` | 两个日期差（天） | `DATEDIFF('2024-01-10','2024-01-01') = 9` |
| `YEAR` / `MONTH` / `DAY` | 取年/月/日 | `YEAR('2024-01-01') = 2024` |
| `DATE_ADD` | 日期加 | `DATE_ADD(NOW(), INTERVAL 7 DAY)` |
| `DATE_SUB` | 日期减 | `DATE_SUB(NOW(), INTERVAL 1 MONTH)` |

### 例子

```sql
-- 当前时间
SELECT NOW();

-- 生日格式化
SELECT name, DATE_FORMAT(birthday, '%Y年%m月%d日') AS 生日 FROM students;

-- 算年龄（粗略）
SELECT name, YEAR(CURDATE()) - YEAR(birthday) AS 年龄 FROM students;

-- 生日在 2006 年的
SELECT * FROM students WHERE YEAR(birthday) = 2006;
```

### 常用格式符

| 格式符 | 含义 |
|--------|------|
| `%Y` | 4 位年 |
| `%m` | 月（01-12） |
| `%d` | 日（01-31） |
| `%H` | 小时 |
| `%i` | 分钟 |
| `%s` | 秒 |

> ⚠️ 格式符**大小写敏感**：`%m` 是月，`%M` 是月份英文名（January）；`%d` 是日，`%D` 是星期（Monday）。

## 四、条件函数

### 1. IF

```sql
SELECT name, IF(score >= 60, '及格', '不及格') AS 结果 FROM students;
```

`IF(条件, 真时的值, 假时的值)`，只能两个分支。

### 2. IFNULL

```sql
-- 如果 score 是 NULL，显示 0
SELECT name, IFNULL(score, 0) FROM students;
```

`IFNULL(值, 为NULL时的替换值)`，专门处理 NULL。

### 3. NULLIF

```sql
SELECT NULLIF(10, 10);  -- NULL（两个相等 → NULL）
SELECT NULLIF(10, 20);  -- 10（不相等 → 返回第一个）
```

### 4. CASE WHEN（最常用）

```sql
SELECT name, score,
    CASE
        WHEN score >= 90 THEN '优秀'
        WHEN score >= 80 THEN '良好'
        WHEN score >= 60 THEN '及格'
        ELSE '不及格'
    END AS 等级
FROM students;
```

**CASE 两种写法：**

```sql
-- 写法一：CASE WHEN 条件（判断复杂条件用这个）
CASE
    WHEN score >= 90 THEN '优秀'
    ELSE '其他'
END

-- 写法二：CASE 字段 WHEN 值（对同一字段做等值匹配，更简洁）
CASE gender
    WHEN '男' THEN 'Male'
    WHEN '女' THEN 'Female'
    ELSE 'Unknown'
END
```

> 💡 写法一 = if / else if / else；写法二 = 其他语言里的 switch，本质是 `gender = '男'` 这种等值比较。

## 五、综合练习

在 students 表上完成：

1. 查出姓名和分数，格式化成 `张三：85.5分`
2. 姓名转大写
3. 分数四舍五入到整数
4. 生日格式化成 `2006年05月12日`
5. 查出 2006 年出生的学生
6. 用 CASE WHEN 给分数分级：优秀/良好/及格/不及格
7. 如果 score 是 NULL，显示 0

参考：

```sql
-- 1.
SELECT CONCAT(name, '：', score, '分') AS 信息 FROM students;

-- 2.
SELECT UPPER(name) AS 大写姓名 FROM students;

-- 3.
SELECT name, ROUND(score) AS 取整 FROM students;

-- 4.
SELECT name, DATE_FORMAT(birthday, '%Y年%m月%d日') AS 生日 FROM students;

-- 5.
SELECT * FROM students WHERE YEAR(birthday) = 2006;

-- 6.
SELECT name, score,
    CASE
        WHEN score >= 90 THEN '优秀'
        WHEN score >= 80 THEN '良好'
        WHEN score >= 60 THEN '及格'
        ELSE '不及格'
    END AS 等级
FROM students;

-- 7.
SELECT name, IFNULL(score, 0) AS 分数 FROM students;
```

## 六、常见错误

| 错误 | 原因 |
|------|------|
| CONCAT 结果整个变 NULL | 拼接的任何一个值是 NULL，整个结果就是 NULL，用 `IFNULL` 包一下 |
| 格式化出来不对 | 格式符大小写写错，`%Y` 不是 `%y` |
| 语法报错 | `CASE` 忘了写 `END` 结尾 |
| 截取结果不对 | `SUBSTRING` 从 **1** 开始数，不是 0 |

## 七、本节总结

| 类别 | 核心函数 |
|------|----------|
| 字符串 | `CONCAT`、`SUBSTRING`（`SUBSTR`）、`REPLACE`、`UPPER`、`LOWER` |
| 数字 | `ROUND`、`CEIL`、`FLOOR`、`ABS` |
| 日期 | `NOW`、`DATE_FORMAT`、`DATEDIFF`、`YEAR` |
| 条件 | `IF`、`IFNULL`、`CASE WHEN` |

- 函数可以出现在 `SELECT` / `WHERE` / `ORDER BY` 里，比如 `WHERE YEAR(birthday) = 2006`
- CONCAT 里任何一个值是 NULL，结果整个是 NULL → 用 `IFNULL` 兜底
- 判空显示替代值：`IFNULL`；两个分支：`IF`；多个分支：`CASE WHEN`
