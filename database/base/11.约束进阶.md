# 模块 12 —— 约束进阶（Constraint）

> 约束 = 给表里的数据定规矩，防止脏数据、错数据进表。
> 前置：01.建库建表（主键、NOT NULL 已经用过）。

---

## 一、什么是约束？

**约束 = 数据库层面的规则，不符合规则的数据插不进去。**

比如：

- 年龄不能是负数
- 邮箱不能重复
- 性别只能是男/女
- 班级 id 必须真实存在

---

## 二、6 种常见约束

| 约束 | 作用 | 关键字 |
|------|------|--------|
| 主键 | 唯一标识一行 | `PRIMARY KEY` |
| 非空 | 不能为空 | `NOT NULL` |
| 唯一 | 值不能重复 | `UNIQUE` |
| 默认值 | 不填时用默认值 | `DEFAULT` |
| 检查 | 值必须满足条件 | `CHECK` |
| 外键 | 关联另一张表 | `FOREIGN KEY` |

> 主键和 NOT NULL 你已经用过，本模块重点讲 **UNIQUE、DEFAULT、CHECK、外键**。

---

## 三、UNIQUE —— 唯一约束

值不能重复。

### 建表时

```sql
CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) UNIQUE,
    email VARCHAR(100) UNIQUE
);
```

### 建表后添加

```sql
ALTER TABLE users ADD UNIQUE (email);
```

### 测试

```sql
INSERT INTO users (username, email) VALUES ('张三', 'a@test.com');  -- 成功
INSERT INTO users (username, email) VALUES ('李四', 'a@test.com');  -- 报错：Duplicate entry
```

> 💡 **注意：UNIQUE 允许多个 NULL（NULL 不算重复）。**

### 联合唯一（多列组合起来不能重复，单列可以重复）

```sql
ALTER TABLE users ADD UNIQUE (class_id, name);
```

表示：**同一个班级里不能有重名，但不同班级可以有同名。**

```sql
INSERT INTO users (class_id, name) VALUES (1, '张三');  -- 成功
INSERT INTO users (class_id, name) VALUES (2, '张三');  -- 成功（不同班级）
INSERT INTO users (class_id, name) VALUES (1, '张三');  -- 报错（同班级重名）
```

删除联合唯一，索引名取第一列名：

```sql
ALTER TABLE users DROP INDEX class_id;
```

> 💡 联合唯一很常用，比如：学生表 `(class_id, student_no)`、订单表 `(order_no, item_no)`。
>
> ⚠️ **踩坑提醒：联合唯一和单列唯一是两回事。** 如果表上之前加过单独的 `ADD UNIQUE (email)`，它会要求全表 email 不重复，和联合唯一 `(class_id, email)` 互不影响。UPDATE 时报 Duplicate 但联合唯一没问题时，先用 `SHOW INDEX FROM 表名;` 检查是不是残留的单列唯一索引在挡。

## 四、DEFAULT —— 默认值

不填这个字段时，自动用默认值。

### 建表时

```sql
CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) NOT NULL,
    status INT DEFAULT 1,                        -- 默认状态 1
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP  -- 默认当前时间
);
```

### 测试

```sql
-- 不填 status，自动是 1
INSERT INTO users (username) VALUES ('张三');
```

### 建表后修改默认值

```sql
ALTER TABLE users ALTER COLUMN status SET DEFAULT 0;
```

## 五、CHECK —— 检查约束

值必须满足指定条件。

### 建表时

```sql
CREATE TABLE students (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(50) NOT NULL,
    age INT CHECK (age >= 0 AND age <= 150),
    gender CHAR(1) CHECK (gender IN ('男', '女')),
    score DECIMAL(5,2) CHECK (score >= 0 AND score <= 100)
);
```

### 测试

```sql
INSERT INTO students (name, age) VALUES ('张三', 18);     -- 成功
INSERT INTO students (name, age) VALUES ('李四', -5);     -- 报错：CHECK 失败
INSERT INTO students (name, gender) VALUES ('王五', '未知'); -- 报错：CHECK 失败
```

### 建表后添加

```sql
ALTER TABLE students ADD CHECK (score >= 0 AND score <= 100);
```

> ⚠️ **注意：MySQL 8.0.16 之前 CHECK 是摆设（写了不生效），8.0.16 之后才真正生效。**

## 六、外键 —— FOREIGN KEY（重点）

**外键 = 一张表的字段，引用另一张表的主键。**

### 为什么需要外键？

假设 students 表有 class_id，如果随便填个 999，但 classes 表里根本没有 id=999 的班级，数据就乱了。

外键保证：**class_id 必须是 classes 表里真实存在的 id。**

### 建表时

```sql
CREATE TABLE students (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(50) NOT NULL,
    class_id INT,
    FOREIGN KEY (class_id) REFERENCES classes(id)
);
```

- `FOREIGN KEY (class_id)`：本表的 class_id 是外键
- `REFERENCES classes(id)`：引用 classes 表的 id

### 测试

```sql
-- classes 表有 id=1,2,3
INSERT INTO students (name, class_id) VALUES ('张三', 1);   -- 成功
INSERT INTO students (name, class_id) VALUES ('李四', 999); -- 报错：外键约束失败
```

### 建表后添加

```sql
ALTER TABLE students
ADD CONSTRAINT fk_class
FOREIGN KEY (class_id) REFERENCES classes(id);
```

### 删除外键

```sql
ALTER TABLE students DROP FOREIGN KEY fk_class;
```

### 级联操作（了解）

```sql
FOREIGN KEY (class_id) REFERENCES classes(id)
    ON DELETE CASCADE    -- 删班级时，自动删该班学生
    ON UPDATE CASCADE    -- 改班级 id 时，自动改学生表的 class_id
```

| 选项 | 作用 |
|------|------|
| `CASCADE` | 级联，跟着删/改 |
| `SET NULL` | 设为 NULL |
| `RESTRICT` | 拒绝删除（默认） |
| `NO ACTION` | 同 RESTRICT |

> 💡 **新手建议：先不用级联，默认 RESTRICT（有引用就不让删）最安全。**

## 七、约束的查看与删除

### 查看

```sql
-- 查看表的约束
SHOW CREATE TABLE students;

-- 查看外键
SELECT * FROM information_schema.KEY_COLUMN_USAGE
WHERE TABLE_NAME = 'students';
```

### 删除

```sql
-- 删除 UNIQUE
ALTER TABLE users DROP INDEX email;

-- 删除 CHECK
ALTER TABLE students DROP CHECK students_chk_1;

-- 删除外键
ALTER TABLE students DROP FOREIGN KEY fk_class;
```

## 八、综合建表示例

```sql
CREATE TABLE students (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(50) NOT NULL,
    age INT CHECK (age >= 0 AND age <= 150),
    gender CHAR(1) CHECK (gender IN ('男', '女')),
    score DECIMAL(5,2) DEFAULT 0 CHECK (score >= 0 AND score <= 100),
    email VARCHAR(100) UNIQUE,
    class_id INT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (class_id) REFERENCES classes(id)
);
```

这张表把所有约束都用上了：主键、非空、CHECK、默认值、唯一、外键。

## 九、常见错误

| 错误 | 原因 |
|------|------|
| `Duplicate entry` | 违反 UNIQUE |
| `Check constraint violated` | 违反 CHECK |
| `Cannot add or update a child row` | 外键引用的值不存在 |
| `Cannot delete or update a parent row` | 被外键引用的行不能删 |
| CHECK 不生效 | MySQL 版本 < 8.0.16 |

## 十一、一句话总结

| 约束 | 作用 | 例子 |
|------|------|------|
| UNIQUE | 值不能重复 | 邮箱、用户名 |
| DEFAULT | 不填用默认值 | status 默认 1 |
| CHECK | 值必须满足条件 | age 0~150 |
| FOREIGN KEY | 引用另一张表的主键 | class_id → classes.id |
