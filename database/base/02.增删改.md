# 模块 2 —— 增删改（INSERT / UPDATE / DELETE）

> 前置：建库建表见 `01.建库建表.md`。本节所有示例都基于 students 表：

```sql
DESC students;
-- id        INT          主键，自增
-- name      VARCHAR(50)  姓名
-- age       INT          年龄
-- gender    CHAR(2)      性别
-- score     DECIMAL(5,2) 成绩
-- birthday  DATE         生日
```

---

## 一、INSERT —— 插入数据

### 1. 语法

```sql
INSERT INTO 表名 (字段1, 字段2, ...) VALUES (值1, 值2, ...);
```

### 2. 插入一条

```sql
INSERT INTO students (name, age, gender, score, birthday)
VALUES ('张三', 18, '男', 85.5, '2006-05-12');
```

注意：

- 字符串用单引号 `'张三'`
- 日期也用单引号 `'2006-05-12'`
- `id` 不用写，因为它是 `AUTO_INCREMENT` 自动增长

### 3. 插入多条

```sql
INSERT INTO students (name, age, gender, score, birthday) VALUES
('李四', 19, '女', 92.0, '2005-08-20'),
('王五', 20, '男', 78.5, '2004-03-15'),
('赵六', 18, '女', 88.0, '2006-11-01'),
('钱七', 21, '男', 95.5, '2003-07-09');
```

### 4. 只插部分字段

没写的字段会是 NULL（或有默认值）：

```sql
INSERT INTO students (name, age) VALUES ('周九', 20);
-- 结果：gender、score、birthday 都是 NULL
```

### 5. 插入时省略字段名（不推荐）

如果所有字段都按建表顺序填，可以省略字段名：

```sql
INSERT INTO students VALUES
(NULL, '孙八', 22, '男', 80.0, '2002-01-01');
-- NULL 对应 id，让它自动增长
```

> ⚠️ 不推荐这种写法：值必须和建表顺序一一对应，表一加列就容易插错位置，建议永远写全字段名。

---

## 二、UPDATE —— 修改数据

### 1. 语法

```sql
UPDATE 表名 SET 字段 = 新值 WHERE 条件;
```

### 2. 修改一条

```sql
UPDATE students SET score = 90.0 WHERE name = '张三';
```

### 3. 修改多个字段

```sql
UPDATE students SET score = 91.0, age = 19 WHERE name = '张三';
```

### 4. 批量修改

```sql
-- 所有男生分数 +2
UPDATE students SET score = score + 2 WHERE gender = '男';
```

### 5. ⚠️ 危险：不写 WHERE

```sql
UPDATE students SET score = 100;
-- 这会把整张表所有行的 score 都改成 100！
```

> 🔒 铁律：UPDATE 一定要写 WHERE，除非你真的想改全表。

---

## 三、DELETE —— 删除数据

### 1. 语法

```sql
DELETE FROM 表名 WHERE 条件;
```

### 2. 删除一条

```sql
DELETE FROM students WHERE name = '钱七';
```

### 3. 删除多条

```sql
DELETE FROM students WHERE score < 80;
```

### 4. ⚠️ 危险：不写 WHERE

```sql
DELETE FROM students;
-- 这会清空整张表！
```

> 🔒 铁律：DELETE 一定要写 WHERE，除非你真的想清空全表。

### 5. 清空全表（谨慎）

```sql
TRUNCATE TABLE students;
```

和 `DELETE FROM students;` 的区别：

| | DELETE FROM 表名 | TRUNCATE TABLE 表名 |
|---|---|---|
| 速度 | 慢（一行一行删） | 快（直接重置表） |
| 能回滚吗 | 能 | 不能 |
| 自增 ID | 从断点继续 | 从 1 重新数 |
| 能加 WHERE 吗 | 能 | 不能（只能清空） |

---

## 四、查看结果

每次操作后，验证一下：

```sql
SELECT * FROM students;
```

> 💡 建议养成习惯：执行完 INSERT / UPDATE / DELETE，马上 SELECT 看一眼，确认改的是不是自己想改的行。

---

## 五、三个操作对比

| 操作 | 作用 | 关键字 | 危险点 |
|------|------|--------|--------|
| INSERT | 插入数据 | `INSERT INTO ... VALUES` | 字段顺序要和值对应 |
| UPDATE | 修改数据 | `UPDATE ... SET ... WHERE` | 不写 WHERE 改全表 |
| DELETE | 删除数据 | `DELETE FROM ... WHERE` | 不写 WHERE 清空表 |

## 六、练习任务

在 students 表里完成：

1. 插入 3 个新学生（自己编名字、年龄、性别、分数、生日）
2. 把李四的分数改成 95
3. 把所有女生分数 +1
4. 删除年龄大于 21 的学生
5. 查询整张表，看结果

参考：

```sql
-- 1.
INSERT INTO students (name, age, gender, score, birthday) VALUES
('甲同学', 18, '男', 76.0, '2008-01-01'),
('乙同学', 19, '女', 81.5, '2007-02-02'),
('丙同学', 20, '男', 89.0, '2006-03-03');

-- 2.
UPDATE students SET score = 95 WHERE name = '李四';

-- 3.
UPDATE students SET score = score + 1 WHERE gender = '女';

-- 4.
DELETE FROM students WHERE age > 21;

-- 5.
SELECT * FROM students;
```

## 七、常见错误

| 错误 | 原因 |
|------|------|
| `Unknown column 'xxx'` | 字段名写错 |
| `Column count doesn't match` | 字段数和值数量不一致 |
| `Incorrect date value` | 日期格式不对，用 `'2006-05-12'` |
| `Data too long for column` | 字符串超过了 VARCHAR 长度 |

---

## 八、本节总结

- 增：`INSERT INTO 表 (列...) VALUES (值...)`，永远写全字段名
- 改：`UPDATE 表 SET 列 = 值 WHERE 条件`，改之前先想清楚 WHERE
- 删：`DELETE FROM 表 WHERE 条件`，和 UPDATE 一样 WHERE 不能少
- 清空全表用 `TRUNCATE`，快但不可回滚、自增 ID 归 1
- 每次操作后 `SELECT *` 验证结果
