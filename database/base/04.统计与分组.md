# 模块 4 —— 统计与分组（聚合函数 + GROUP BY + HAVING）

> SQL 从"查数据"进阶到"分析数据"的关键一步。

## 一、前提：确认有数据

```sql
USE learn_sql;

SELECT * FROM students;
```

---

## 二、聚合函数（对一列做统计）

| 函数 | 作用 | 例子 |
|------|------|------|
| `COUNT()` | 统计行数 | `COUNT(*)` |
| `SUM()` | 求和 | `SUM(score)` |
| `AVG()` | 平均值 | `AVG(score)` |
| `MAX()` | 最大值 | `MAX(score)` |
| `MIN()` | 最小值 | `MIN(score)` |

### 1. 基本用法

```sql
-- 总人数
SELECT COUNT(*) FROM students;

-- 总分
SELECT SUM(score) FROM students;

-- 平均分
SELECT AVG(score) FROM students;

-- 最高分、最低分
SELECT MAX(score), MIN(score) FROM students;
```

### 2. 一次统计多项 + 起别名

```sql
SELECT
    COUNT(*) AS 人数,
    AVG(score) AS 平均分,
    MAX(score) AS 最高分
FROM students;
```

> 💡 `COUNT(*)` 统计**行数**；`COUNT(列名)` 统计**该列非 NULL 的行数**，两者在有 NULL 时结果不同。

## 三、GROUP BY —— 分组统计

按某个字段分组，然后对每组做统计。

### 1. 基本用法

```sql
-- 按性别分组，统计每组人数
SELECT gender, COUNT(*) AS 人数
FROM students
GROUP BY gender;
```

结果示例：

| gender | 人数 |
|--------|------|
| 男 | 3 |
| 女 | 2 |

### 2. 多字段分组

```sql
-- 按性别 + 年龄分组
SELECT gender, age, COUNT(*) AS 人数
FROM students
GROUP BY gender, age;
```

### 3. 分组 + 多个聚合

```sql
-- 每个性别的平均分、最高分
SELECT
    gender,
    COUNT(*) AS 人数,
    AVG(score) AS 平均分,
    MAX(score) AS 最高分
FROM students
GROUP BY gender;
```

> ⚠️ **铁律：`SELECT` 里出现的非聚合字段，必须出现在 `GROUP BY` 里。**
> 比如 `SELECT name, COUNT(*) ... GROUP BY gender;` 会报错，因为 `name` 不在 `GROUP BY` 里，MySQL 不知道该显示哪一行的 name。

## 四、HAVING —— 对分组结果筛选

### 1. WHERE 和 HAVING 的区别

| | WHERE | HAVING |
|---|---|---|
| 作用对象 | 分组**前**的行 | 分组**后**的结果 |
| 能用聚合函数吗 | ❌ 不能 | ✅ 能 |
| 位置 | `GROUP BY` **前** | `GROUP BY` **后** |

一句话：`WHERE` 筛**行**，`HAVING` 筛**组**。

### 2. 基本用法

```sql
-- 按性别分组，只显示人数大于 2 的组
SELECT gender, COUNT(*) AS 人数
FROM students
GROUP BY gender
HAVING COUNT(*) > 2;
```

```sql
-- 按性别分组，只显示平均分大于 85 的组
SELECT gender, AVG(score) AS 平均分
FROM students
GROUP BY gender
HAVING AVG(score) > 85;
```

### 3. WHERE + GROUP BY + HAVING 一起用

```sql
-- 先筛出分数 > 60 的，再按性别分组，最后只显示人数 >= 2 的组
SELECT gender, COUNT(*) AS 人数, AVG(score) AS 平均分
FROM students
WHERE score > 60
GROUP BY gender
HAVING COUNT(*) >= 2;
```

执行顺序：

```
FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT
```

## 五、完整语法顺序

```sql
SELECT 字段, 聚合函数
FROM 表
WHERE 条件            -- 筛行（分组前）
GROUP BY 分组字段
HAVING 分组后条件     -- 筛组（分组后）
ORDER BY 排序
LIMIT 条数;
```

> 💡 记忆口诀：**WHERE 在 GROUP BY 前筛行，HAVING 在 GROUP BY 后筛组。**

---

## 六、常见错误

| 错误 | 原因 |
|------|------|
| `SELECT name, COUNT(*) ... GROUP BY gender` 报错 | 非聚合字段 `name` 必须出现在 `GROUP BY` 里 |
| `WHERE COUNT(*) > 2` 报错 | 聚合条件要用 `HAVING`，不能用 `WHERE` |
| 语法报错 | `HAVING` 写在了 `GROUP BY` 前面，顺序错了 |
| `GROUP BY` 后 `SELECT` 只有聚合函数 | 忘了把分组字段写进 `SELECT`，看不到按什么分的组 |

## 七、练习任务

在 students 表里完成：

1. 统计总人数
2. 统计所有学生的平均分
3. 按性别分组，统计每组人数
4. 按性别分组，统计每组的平均分、最高分
5. 按年龄分组，统计每组人数
6. 按性别分组，只显示人数大于 1 的组
7. 先筛出分数 > 80 的学生，再按性别分组，统计人数和平均分

参考：

```sql
-- 1.
SELECT COUNT(*) AS 人数 FROM students;

-- 2.
SELECT AVG(score) AS 平均分 FROM students;

-- 3.
SELECT gender, COUNT(*) AS 人数
FROM students
GROUP BY gender;

-- 4.
SELECT gender, AVG(score) AS 平均分, MAX(score) AS 最高分
FROM students
GROUP BY gender;

-- 5.
SELECT age, COUNT(*) AS 人数
FROM students
GROUP BY age;

-- 6.
SELECT gender, COUNT(*) AS 人数
FROM students
GROUP BY gender
HAVING COUNT(*) > 1;

-- 7.
SELECT gender, COUNT(*) AS 人数, AVG(score) AS 平均分
FROM students
WHERE score > 80
GROUP BY gender;
```

## 八、本节总结

- 聚合函数：`COUNT` / `SUM` / `AVG` / `MAX` / `MIN`，对一列做统计
- `GROUP BY`：按字段分组，对每组统计
- `HAVING`：对分组结果筛选（`WHERE` 筛行，`HAVING` 筛组）
- `SELECT` 里的非聚合字段必须出现在 `GROUP BY` 里
- 执行顺序：`FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT`
