# 模块 13 —— 存储过程与函数（Procedure & Function）

> 存储过程 = 一段存进数据库的 SQL 代码，起个名字，以后 CALL 名字就能执行。
> 前置：前面所有模块。

---

## 一、存储过程（Procedure）

### 1. 是什么？

**存储过程 = 存进数据库的 SQL 代码块。**

类比 Java：就是一个方法。

```java
// Java 方法
public void getStudents() {
    // 逻辑
}
```

```sql
-- 存储过程
CREATE PROCEDURE get_students()
BEGIN
    SELECT * FROM students;
END;
```

### 2. 为什么用？

| 好处 | 说明 |
|------|------|
| 复用 | 写一次，多处调用 |
| 简化 | 复杂逻辑封装，调用方只写一句 CALL |
| 减少网络传输 | 逻辑在数据库端执行，不用来回传 SQL |
| 权限控制 | 只给执行权限，不给表权限 |

### 3. 基本语法

```sql
DELIMITER //

CREATE PROCEDURE 过程名()
BEGIN
    -- SQL 语句
END //

DELIMITER ;
```

**DELIMITER // 是干嘛的？**

MySQL 默认用 `;` 作为语句结束符。存储过程内部也有 `;`，会冲突。所以临时把结束符改成 `//`，写完再改回 `;`。

### 4. 例子 1：无参数

```sql
DELIMITER //

CREATE PROCEDURE get_all_students()
BEGIN
    SELECT * FROM students;
END //

DELIMITER ;
```

调用：

```sql
CALL get_all_students();
```

### 5. 例子 2：带参数（IN）

```sql
DELIMITER //

CREATE PROCEDURE get_students_by_gender(IN g CHAR(1))
BEGIN
    SELECT * FROM students WHERE gender = g;
END //

DELIMITER ;
```

调用：

```sql
CALL get_students_by_gender('男');
```

参数类型：

| 类型 | 含义 |
|------|------|
| `IN` | 输入参数（默认） |
| `OUT` | 输出参数 |
| `INOUT` | 输入+输出 |

### 6. 例子 3：带 OUT 参数

```sql
DELIMITER //

CREATE PROCEDURE count_students(OUT total INT)
BEGIN
    SELECT COUNT(*) INTO total FROM students;
END //

DELIMITER ;
```

调用：

```sql
CALL count_students(@n);
SELECT @n;
```

`@n` 是用户变量，用来接收 OUT 参数。

### 7. 例子 4：带 IF 逻辑

```sql
DELIMITER //

CREATE PROCEDURE check_score(IN s DECIMAL(5,2))
BEGIN
    IF s >= 90 THEN
        SELECT '优秀';
    ELSEIF s >= 60 THEN
        SELECT '及格';
    ELSE
        SELECT '不及格';
    END IF;
END //

DELIMITER ;
```

调用：

```sql
CALL check_score(85);
```

### 8. 例子 5：带循环

```sql
DELIMITER //

CREATE PROCEDURE insert_10_students()
BEGIN
    DECLARE i INT DEFAULT 1;
    WHILE i <= 10 DO
        INSERT INTO students (name, age) VALUES (CONCAT('学生', i), 18 + i);
        SET i = i + 1;
    END WHILE;
END //

DELIMITER ;
```

调用：

```sql
CALL insert_10_students();
```

### 9. 查看和删除

```sql
-- 查看所有存储过程
SHOW PROCEDURE STATUS WHERE Db = 'learn_sql';

-- 查看定义
SHOW CREATE PROCEDURE get_all_students;

-- 删除
DROP PROCEDURE get_all_students;
```

## 二、函数（Function）

### 1. 是什么？

**函数 = 存储过程的"简化版"，但必须返回一个值。**

类比 Java：有返回值的方法。

```java
public int getAvg() {
    return avg;
}
```

### 2. 存储过程 vs 函数（核心区别）

| | 存储过程 | 函数 |
|------|---------|------|
| 返回值 | 可以没有，也可以多个（OUT） | 必须返回一个值 |
| 调用方式 | `CALL 名字()` | `SELECT 名字()` |
| 用在 SQL 里 | ❌ 不能 | ✅ 可以，如 `SELECT get_avg_score()` |
| 参数 | IN / OUT / INOUT | 只有 IN |

> 💡 一句话：**函数能嵌在 SQL 里用，存储过程不能。**

### 3. 语法

```sql
DELIMITER //

CREATE FUNCTION 函数名(参数 类型)
RETURNS 返回类型
DETERMINISTIC
BEGIN
    -- 逻辑
    RETURN 值;
END //

DELIMITER ;
```

`DETERMINISTIC`：表示"同样的输入，输出固定"。不加可能报错。

### 4. 例子 1：无参数函数

```sql
DELIMITER //

CREATE FUNCTION get_avg_score()
RETURNS DECIMAL(5,2)
DETERMINISTIC
BEGIN
    DECLARE avg_score DECIMAL(5,2);
    SELECT AVG(score) INTO avg_score FROM students;
    RETURN avg_score;
END //

DELIMITER ;
```

调用：

```sql
SELECT get_avg_score();
```

也可以用在查询里：

```sql
SELECT name, score, get_avg_score() AS 平均分 FROM students;
```

### 5. 例子 2：带参数的函数

```sql
DELIMITER //

CREATE FUNCTION score_level(s DECIMAL(5,2))
RETURNS VARCHAR(10)
DETERMINISTIC
BEGIN
    DECLARE lv VARCHAR(10);
    IF s >= 90 THEN SET lv = '优秀';
    ELSEIF s >= 60 THEN SET lv = '及格';
    ELSE SET lv = '不及格';
    END IF;
    RETURN lv;
END //

DELIMITER ;
```

调用：

```sql
SELECT name, score, score_level(score) AS 等级 FROM students;
```

### 6. 例子 3：字符串函数

```sql
DELIMITER //

CREATE FUNCTION get_initial(name VARCHAR(50))
RETURNS VARCHAR(1)
DETERMINISTIC
BEGIN
    RETURN LEFT(name, 1);
END //

DELIMITER ;
```

调用：

```sql
SELECT name, get_initial(name) AS 姓氏 FROM students;
```

### 7. 查看和删除

```sql
SHOW FUNCTION STATUS WHERE Db = 'learn_sql';
SHOW CREATE FUNCTION get_avg_score;
DROP FUNCTION get_avg_score;
```

## 三、常用控制语句（存储过程和函数里都能用）

### 1. IF

```sql
IF 条件 THEN
    ...
ELSEIF 条件 THEN
    ...
ELSE
    ...
END IF;
```

### 2. CASE

```sql
CASE 变量
    WHEN 值1 THEN ...
    WHEN 值2 THEN ...
    ELSE ...
END CASE;
```

### 3. WHILE 循环

```sql
WHILE 条件 DO
    ...
END WHILE;
```

### 4. 变量声明

```sql
DECLARE 变量名 类型 DEFAULT 默认值;
```

### 5. 变量赋值

```sql
SET 变量名 = 值;
```

## 五、常见错误

| 错误 | 原因 |
|------|------|
| `You have an error in your SQL syntax` | 忘了 DELIMITER |
| `FUNCTION already exists` | 函数已存在，先 DROP |
| `Not allowed to return a result set from a function` | 函数里不能 SELECT 结果集，要用 INTO |
| `This function has none of DETERMINISTIC` | 函数没写 DETERMINISTIC |
| DELIMITER 后没改回来 | 后面 SQL 全报错 |

## 六、一句话总结

| | 存储过程 | 函数 |
|------|---------|------|
| 是什么 | 存进数据库的 SQL 代码块 | 必须返回值，可嵌在 SQL 里 |
| 调用 | `CALL 名字()` | `SELECT 名字()` |
| 返回值 | 可有可无 | 必须有 |
| 用途 | 封装复杂业务逻辑 | 封装计算、转换逻辑 |
