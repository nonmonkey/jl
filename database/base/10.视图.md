# 模块 11 —— 视图（View）

> 视图 = 一条存起来的 SELECT 语句，用起来像表，但不存真实数据。
> 你可以把它理解成：给一条复杂查询起个名字，以后直接用这个名字查。

---

## 一、什么是视图？

**视图 = 存起来的 SELECT。**

- 它不存真实数据，只是一条查询语句
- 用起来和表一样：`SELECT * FROM 视图名`
- 查视图 = 实时执行它背后的 SELECT

---

## 二、为什么用视图？

| 好处 | 说明 |
|------|------|
| 简化查询 | 复杂 SQL 存成视图，以后一句 `SELECT * FROM 视图` 就行 |
| 隐藏敏感字段 | 比如只暴露姓名、班级，不暴露身份证号 |
| 统一口径 | 多个地方用同一个视图，逻辑一致 |
| 权限控制 | 只给用户视图权限，不给原表权限 |

---

## 三、创建视图

### 语法

```sql
CREATE VIEW 视图名 AS
SELECT ...;
```

### 1. 简单视图

```sql
-- 只查男生的姓名和分数
CREATE VIEW v_male_students AS
SELECT name, score
FROM students
WHERE gender = '男';
```

以后直接：

```sql
SELECT * FROM v_male_students;
```

### 2. 带 JOIN 的视图

```sql
-- 学生 + 班级名
CREATE VIEW v_student_class AS
SELECT s.name, s.score, c.class_name
FROM students2 s
LEFT JOIN classes c ON s.class_id = c.id;
```

### 3. 带统计的视图

```sql
-- 每个班级的人数、平均分
CREATE VIEW v_class_stats AS
SELECT
    c.class_name,
    COUNT(*) AS 人数,
    AVG(s.score) AS 平均分
FROM students2 s
JOIN classes c ON s.class_id = c.id
GROUP BY c.class_name;
```

## 五、使用视图

和普通表一样用，可以加 WHERE、ORDER BY、LIMIT、JOIN：

```sql
SELECT * FROM v_male_students;

SELECT * FROM v_male_students WHERE score > 85;

SELECT * FROM v_student_class WHERE class_name = '一班';
```

---

## 六、修改视图

### 方法一：CREATE OR REPLACE

```sql
CREATE OR REPLACE VIEW v_male_students AS
SELECT name, score, age
FROM students
WHERE gender = '男';
```

### 方法二：ALTER VIEW

```sql
ALTER VIEW v_male_students AS
SELECT name, score, age
FROM students
WHERE gender = '男';
```

---

## 七、删除视图

```sql
DROP VIEW v_male_students;
```

---

## 八、视图能不能改数据？

分情况：

| 视图类型 | 能否 INSERT/UPDATE/DELETE |
|----------|---------------------------|
| 简单视图（单表、无聚合、无 DISTINCT） | ✅ 可以，会改到原表 |
| 复杂视图（JOIN、GROUP BY、聚合函数） | ❌ 不能改 |

```sql
-- 简单视图，可以改（实际改的是 students 表）
UPDATE v_male_students SET score = 90 WHERE name = '张三';

-- 复杂视图，不能改，会报错
UPDATE v_student_class SET score = 90 WHERE name = '张三';
```

> 💡 **建议：视图只用来查，改数据直接操作原表，更清晰。**

---

## 九、视图的注意事项

| 注意 | 说明 |
|------|------|
| 视图不存数据 | 查视图 = 执行它背后的 SELECT |
| 原表变了，视图结果也变 | 视图是"实时"的 |
| 视图可以嵌套视图 | 但别嵌套太深，影响性能 |
| 视图名不要和表名冲突 | 同一数据库内名字唯一 |

---

## 十一、一句话总结

- 视图 = 存起来的 SELECT，用起来像表，不存数据
- 创建：`CREATE VIEW 视图名 AS SELECT ...;`
- 使用：`SELECT * FROM 视图名;`
- 修改：`CREATE OR REPLACE VIEW` 或 `ALTER VIEW`
- 删除：`DROP VIEW 视图名;`
- 简单视图可改数据，复杂视图不能改
