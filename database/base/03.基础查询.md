## 二、SELECT —— 查数据

### 1. 查全部

```sql
SELECT * FROM students;
```

- `*` 表示所有字段
- `FROM students` 表示从 students 表查

### 2. 查指定字段

```sql
SELECT name, score FROM students;
```

只显示 name 和 score 两列。

### 3. 给字段起别名（AS）

```sql
SELECT name AS 姓名, score AS 分数 FROM students;
```

结果列名会显示"姓名""分数"。

> 💡 `AS` 可以省略，`name 姓名` 也行，但建议写 AS，更清楚。

## 三、WHERE —— 条件筛选

### 1. 基本语法

```sql
SELECT * FROM students WHERE 条件;
```

### 2. 常用运算符

| 运算符 | 含义 | 例子 |
|--------|------|------|
| `=` | 等于 | `WHERE gender = '男'` |
| `!=` 或 `<>` | 不等于 | `WHERE gender != '男'` |
| `>` | 大于 | `WHERE score > 85` |
| `<` | 小于 | `WHERE age < 20` |
| `>=` | 大于等于 | `WHERE score >= 90` |
| `<=` | 小于等于 | `WHERE age <= 18` |

### 3. 多条件：AND / OR

```sql
-- 男生 且 分数大于 80
SELECT * FROM students WHERE gender = '男' AND score > 80;

-- 男生 或 分数大于 90
SELECT * FROM students WHERE gender = '男' OR score > 90;
```

- `AND`：两个条件**都**满足
- `OR`：满足**一个**就行

#### ⚠️ 优先级：AND 比 OR 先算

`AND` 和 `OR` 混用时，**`AND` 优先级更高**（先算 AND，再算 OR）。不写括号时：

```sql
WHERE gender = '男' AND score > 30 OR height > 170
-- 实际等价于：
WHERE (gender = '男' AND score > 30) OR (height > 170)
-- 即：（男生且分>30）或（身高>170）——身高>170 的女生也会被查出来
```

**用括号改变分组**，同一个条件不同括号结果完全不同：

```sql
-- 想要：男生中，（分>30 或 身高>170）
WHERE gender = '男' AND (score > 30 OR height > 170)
```

| 写法 | 实际筛选 |
|------|----------|
| `gender='男' AND score>30 OR height>170` | （男且分>30）**或** 身高>170 |
| `gender='男' AND (score>30 OR height>170)` | 男，**且**（分>30 或 身高>170） |
| `(gender='男' OR height>170) AND score>30` | （男 或 身高>170），且 分>30 |

> 🔒 铁律：`AND` 和 `OR` 混用时，**永远加括号**，不依赖默认优先级。

### 4. 范围：BETWEEN

```sql
-- 分数在 80 到 90 之间（含 80 和 90）
SELECT * FROM students WHERE score BETWEEN 80 AND 90;
```

### 5. 列表：IN

```sql
-- 年龄是 18 或 20
SELECT * FROM students WHERE age IN (18, 20);
```

### 6. 模糊查询：LIKE

```sql
-- 姓张的
SELECT * FROM students WHERE name LIKE '张%';

-- 名字里带"三"的
SELECT * FROM students WHERE name LIKE '%三%';

-- 姓张，且名字只有两个字
SELECT * FROM students WHERE name LIKE '张_';
```

| 通配符 | 含义 |
|--------|------|
| `%` | 任意多个字符（包括 0 个） |
| `_` | 任意**一个**字符 |

### 7. 空值：IS NULL

```sql
SELECT * FROM students WHERE score IS NULL;

SELECT * FROM students WHERE score IS NOT NULL;
```

> ⚠️ 判断空值用 `IS NULL`，**不能**写 `= NULL`（因为 NULL 和任何值比较都不是"相等"，详见 `01.建库建表.md` 的 UNIQUE 部分）。

## 四、ORDER BY —— 排序

### 1. 升序（默认）

```sql
SELECT * FROM students ORDER BY score ASC;
```

### 2. 降序

```sql
SELECT * FROM students ORDER BY score DESC;
```

### 3. 多字段排序

```sql
-- 先按年龄升序，年龄相同再按分数降序
SELECT * FROM students ORDER BY age ASC, score DESC;
```

---

## 五、LIMIT —— 限制条数

### 1. 取前 N 条

```sql
SELECT * FROM students LIMIT 3;
```

### 2. 分页（跳过 M 条，取 N 条）

```sql
-- 跳过前 2 条，取 3 条
SELECT * FROM students LIMIT 2, 3;
```

### 3. 经典组合：TOP N

```sql
-- 分数最高的前 3 名
SELECT * FROM students ORDER BY score DESC LIMIT 3;
```

> 💡 `ORDER BY ... DESC` + `LIMIT n` = "取最大的前 n 个"，这是最高频的组合之一。

---

## 六、综合示例

```sql
-- 查分数大于 80 的女生，按分数从高到低，取前 2 名
SELECT name, score
FROM students
WHERE gender = '女' AND score > 80
ORDER BY score DESC
LIMIT 2;
```

书写顺序：

```
SELECT → FROM → WHERE → ORDER BY → LIMIT
```

---

## 七、执行顺序（理解这个很重要）

SQL **写的顺序**和**执行的顺序**不一样：

| 书写顺序 | 执行顺序 |
|----------|----------|
| FROM | 1️⃣ |
| WHERE | 2️⃣ |
| SELECT | 3️⃣ |
| ORDER BY | 4️⃣ |
| LIMIT | 5️⃣ |

先找表（FROM）→ 筛条件（WHERE）→ 选字段（SELECT）→ 排序（ORDER BY）→ 限条数（LIMIT）。

> 💡 为什么是这个顺序？因为必须先有表（FROM）、再按条件筛（WHERE），筛完才知道有哪些行，才能选字段（SELECT）、排序（ORDER BY）、截断（LIMIT）。

## 八、练习任务

在 students 表里完成：

1. 查所有学生
2. 只查姓名和分数
3. 查所有男生
4. 查分数大于 85 的女生
5. 查年龄在 18 到 20 之间的学生
6. 查姓张的学生
7. 按分数从高到低排序
8. 查分数最高的前 2 名
9. 查分数在 80~90 之间、且是男生的学生，按分数降序

参考：

```sql
-- 1.
SELECT * FROM students;

-- 2.
SELECT name, score FROM students;

-- 3.
SELECT * FROM students WHERE gender = '男';

-- 4.
SELECT * FROM students WHERE score > 85 AND gender = '女';

-- 5.
SELECT * FROM students WHERE age BETWEEN 18 AND 20;

-- 6.
SELECT * FROM students WHERE name LIKE '张%';

-- 7.
SELECT * FROM students ORDER BY score DESC;

-- 8.
SELECT * FROM students ORDER BY score DESC LIMIT 2;

-- 9.
SELECT * FROM students
WHERE score BETWEEN 80 AND 90 AND gender = '男'
ORDER BY score DESC;
```

## 九、常见错误

| 错误 | 原因 |
|------|------|
| `Unknown column` | 字段名写错 |
| 查询结果不对 | 字符串忘加引号，`WHERE name = 张三` ❌，要 `= '张三'` |
| 判断空值没结果 | 用了 `= NULL`，应该用 `IS NULL` |
| 语法报错 | 顺序错，`ORDER BY` 要写在 `WHERE` 后面 |

---

## 十、本节总结

- `SELECT` 查数据，`*` 全部、列名指定、`AS` 起别名
- `WHERE` 筛条件：比较运算符、`AND/OR`（混用时加括号，AND 优先级更高）、`BETWEEN`、`IN`、`LIKE`、`IS NULL`
- `ORDER BY` 排序：`ASC` 升 / `DESC` 降，可多字段
- `LIMIT` 限条数，`ORDER BY DESC + LIMIT n` = 取最大的前 n 个
- 执行顺序：`FROM → WHERE → SELECT → ORDER BY → LIMIT`，和书写顺序不同
- 字符串要加引号，判空用 `IS NULL`
