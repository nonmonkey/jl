# 模块 5 —— 多表查询（JOIN）

> SQL 里最核心、最像"真正开发"的部分。实际工作里，数据几乎都分散在多张表里，必须靠 JOIN 拼起来。
> 前置：建表、聚合与分组见 `01.建库建表.md`、`04.统计与分组.md`。

---

## 一、为什么要多表查询？

假设你有两张表：

**students（学生表）**

| id | name | class_id |
|----|------|----------|
| 1 | 张三 | 1 |
| 2 | 李四 | 2 |
| 3 | 王五 | 1 |

**classes（班级表）**

| id | class_name |
|----|------------|
| 1 | 一班 |
| 2 | 二班 |

你想查"每个学生属于哪个班"，就需要把两张表关联起来——这就是 JOIN。

> 💡 学生表里只存了 `class_id`（数字），不存班级名，这样班级改名时只改一处，所有学生自动生效。这就是"拆表"的意义。

---

## 二、先建两张练习表

在 learn_sql 里新建查询，运行：

```sql
-- 班级表
CREATE TABLE IF NOT EXISTS classes (
    id INT PRIMARY KEY AUTO_INCREMENT,
    class_name VARCHAR(50) NOT NULL
);

-- 学生表（带 class_id 外键）
CREATE TABLE IF NOT EXISTS students2 (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(50) NOT NULL,
    age INT,
    gender CHAR(1),
    score DECIMAL(5,2),
    class_id INT
);
```

插入数据：

```sql
INSERT INTO classes (class_name) VALUES
('一班'), ('二班'), ('三班');

INSERT INTO students2 (name, age, gender, score, class_id) VALUES
('张三', 18, '男', 85.5, 1),
('李四', 19, '女', 92.0, 2),
('王五', 20, '男', 78.5, 1),
('赵六', 18, '女', 88.0, 3),
('钱七', 21, '男', 95.5, NULL);
```

> ⚠️ 注意：钱七的 `class_id` 是 NULL，没有班级。后面会用到这个。

---

## 三、INNER JOIN —— 内连接（最常用）

只返回**两张表都匹配得上**的行。

### 1. 语法

```sql
SELECT 字段
FROM 表A
INNER JOIN 表B ON 表A.关联字段 = 表B.关联字段;
```

### 2. 例子

```sql
-- 查每个学生及其班级名
SELECT s.name, s.score, c.class_name
FROM students2 AS s
INNER JOIN classes AS c ON s.class_id = c.id;
```

结果：

| name | score | class_name |
|------|-------|------------|
| 张三 | 85.5 | 一班 |
| 李四 | 92.0 | 二班 |
| 王五 | 78.5 | 一班 |
| 赵六 | 88.0 | 三班 |

钱七没出现，因为他 `class_id` 是 NULL，匹配不上。

### 3. 简写

`INNER JOIN` 可以简写成 `JOIN`：

```sql
SELECT s.name, c.class_name
FROM students2 s
JOIN classes c ON s.class_id = c.id;
```

---

## 四、LEFT JOIN —— 左连接

返回**左表所有行**，右表匹配不上的显示 NULL。

```sql
SELECT s.name, s.score, c.class_name
FROM students2 AS s
LEFT JOIN classes AS c ON s.class_id = c.id;
```

结果：

| name | score | class_name |
|------|-------|------------|
| 张三 | 85.5 | 一班 |
| 李四 | 92.0 | 二班 |
| 王五 | 78.5 | 一班 |
| 赵六 | 88.0 | 三班 |
| 钱七 | 95.5 | NULL |

钱七出现了，班级显示 NULL。

> 💡 用途：查"所有学生，包括没分班的"。

---

## 五、RIGHT JOIN —— 右连接

返回**右表所有行**，左表匹配不上的显示 NULL。

```sql
SELECT s.name, c.class_name
FROM students2 AS s
RIGHT JOIN classes AS c ON s.class_id = c.id;
```

结果：

| name | class_name |
|------|------------|
| 张三 | 一班 |
| 王五 | 一班 |
| 李四 | 二班 |
| 赵六 | 三班 |

一班出现两次（张三、王五），因为右表 classes 所有行都保留。

> 💡 实际用得少，因为 `A RIGHT JOIN B` 等价于 `B LEFT JOIN A`，换成 LEFT JOIN 写更直观。

---

## 六、三种 JOIN 对比

| JOIN | 返回什么 |
|------|----------|
| INNER JOIN | 两表都匹配的行 |
| LEFT JOIN | 左表全部 + 右表匹配的（没匹配填 NULL） |
| RIGHT JOIN | 右表全部 + 左表匹配的（没匹配填 NULL） |

图示：

```
INNER JOIN：  A ∩ B
LEFT JOIN：   A 全部（B 没有的填 NULL）
RIGHT JOIN：  B 全部（A 没有的填 NULL）
```

---

## 七、多表 JOIN（3 张以上）

```sql
SELECT s.name, c.class_name, t.teacher_name
FROM students2 s
JOIN classes c ON s.class_id = c.id
JOIN teachers t ON c.teacher_id = t.id;
```

一次 JOIN 一张表，串起来就行。

---

## 八、JOIN + WHERE + GROUP BY 综合

```sql
-- 每个班级的人数、平均分
SELECT
    c.class_name,
    COUNT(*) AS 人数,
    AVG(s.score) AS 平均分
FROM students2 s
JOIN classes c ON s.class_id = c.id
GROUP BY c.class_name;
```

---

## 九、表别名的意义

```sql
FROM students2 AS s
JOIN classes AS c ON s.class_id = c.id
```

- `s` 是 students2 的别名，`c` 是 classes 的别名
- 字段用 `s.name`、`c.class_name` 明确来自哪张表
- 多表查询时，字段前**必须**加表别名，否则容易歧义

---

## 十、常见错误

| 错误 | 原因 |
|------|------|
| `Unknown column 'name'` | 两张表都有 name，必须写 `s.name` |
| `Unknown column 's.class_id'` | 表别名写错 |
| JOIN 结果变多 | 关联条件写错，出现笛卡尔积 |
| 语法报错 | 忘记 `ON`，`JOIN` 必须跟 `ON` 条件 |

## 十一、练习任务

1. 查每个学生及其班级名（INNER JOIN）
2. 查所有学生，包括没班级的（LEFT JOIN）
3. 查每个班级的学生人数
4. 查每个班级的平均分，按平均分降序
5. 查一班的所有学生
6. 查没有班级的学生（`WHERE c.id IS NULL`）

参考：

```sql
-- 1.
SELECT s.name, c.class_name
FROM students2 s
JOIN classes c ON s.class_id = c.id;

-- 2.
SELECT s.name, c.class_name
FROM students2 s
LEFT JOIN classes c ON s.class_id = c.id;

-- 3.
SELECT c.class_name, COUNT(*) AS 人数
FROM students2 s
JOIN classes c ON s.class_id = c.id
GROUP BY c.class_name;

-- 4.
SELECT c.class_name, AVG(s.score) AS 平均分
FROM students2 s
JOIN classes c ON s.class_id = c.id
GROUP BY c.class_name
ORDER BY 平均分 DESC;

-- 5.
SELECT s.name
FROM students2 s
JOIN classes c ON s.class_id = c.id
WHERE c.class_name = '一班';

-- 6.（LEFT JOIN + IS NULL 是查"没匹配上"的经典套路）
SELECT s.name
FROM students2 s
LEFT JOIN classes c ON s.class_id = c.id
WHERE c.id IS NULL;
```

---

## 十二、本节总结

- `INNER JOIN`：只要两边都匹配的
- `LEFT JOIN`：左表全要，右表匹配不上填 NULL
- `RIGHT JOIN`：右表全要（用得少）
- 多表 JOIN：一张张串
- 字段加表别名：`s.name`、`c.class_name`
- 查"没匹配上的数据"：`LEFT JOIN` + `WHERE 右表主键 IS NULL`
